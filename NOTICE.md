## MVP changes

- Original frontend retained, with new Memory editor behavior and a connection section inside Settings.
- New small Node backend plus Vercel adapter. Text-only OpenAI-compatible chat with explicit memory context, no fake AI responses.
- Original cloud adapters replaced by browser-local adapters. No original database or account credentials are used.
- Unsupported cloud authentication, simulated MFA/encryption, source-code auto-repair and image-service fallback disabled. Security/storage wording corrected where it described unavailable features.
- Source attribution retained. No old Git history, environment files, APK, Android project, database migrations, bundled development-guidance directories or alternate unused backend included.

Exact UI means the original layout/components/styles/assets are preserved, not that false feature claims remain uncorrected. Nonessential screens are visibly marked as preview/sample screens when opened. Chat, history and user-managed memory are the working demonstration path.
